# Hide right sidebar and always switch to Following on X.com

Minimal Chrome extension for a cleaner X/Twitter experience.

## Features

* Hides the right sidebar
* Removes trends and “Who to follow”
* Automatically switches from “For you” to “Following”
* Works on both:

  * x.com
  * twitter.com

## Installation

### Manual install (Developer Mode)

1. Download or clone this repository
2. Open Chrome
3. Go to:

```text
chrome://extensions
```

4. Enable **Developer mode**
5. Click **Load unpacked**
6. Select the extension folder

Done.

## Files

* `manifest.json` → Chrome extension manifest
* `content.js` → Main logic

## Why?

X/Twitter constantly switches users back to the algorithmic “For you” feed and fills the interface with trends, recommendations, and distractions.

This extension keeps the experience minimal and focused on accounts you actually follow.
